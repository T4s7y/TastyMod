## Jokers
[X] **Snowball**: +4$ at the end of round for each consecutive blind won with one hand.
[X] **Read Guard**: retrigger the last 2 played cards used in scoring one additional time
[X]] **Bleed From Within**: at the start of each round destroy a random card from your deck.
[X] **Beer**: Sell this joker to obtain a discard for this round.
[X] **Alcoholic**: Gain a negative copy of **Beer** if played poker hand is [poker hand], poker hand changes each round.
[X] **Grey**: +1x mult for every grey seal in deck (Must have grey seal to appear).
[X] **His Majesty**: If played hand contains exactly one card, attach an orange seal to it.
[] **Skeleton**: **Bone** cards give x1.1 mult when scored. Counts as a **Bone** card
[] **Void Cat**: Upon pickup consume all **Void Seals** in the deck and obtain the following: 
                 2 seals consumed: create a random **Legendary Joker**.
                 4 seals consumed: enchant 2 random jokers with **Negative**.
                 >6 seals consumed: this joker gains xmult based on the seals consumed.
                 (Must have void seal to appear).   

## Spectrals
[] **Glamour**: select up to 3 cards to enhance with a random enhancement.
[X] **Summon Forth**: Draw all of your orange seal cards.
[X] **Glory**: select one 1 card to attach with an orange seal.
[] **Dying Star**: select 1 card to attach with a void seal.

## Seals
[X] **Orange Seal**: +1$ +4 mult +30 chips per orange seal in deck. At the start of each ante gain **Summon Forth**
[] **Void Seal**: 1 in 2 chance to create a random tarot card. 1 in 4 to create a random spectral (Must have room)

## Enhancements
[] **Bone**: Retrigger once for every other bone card used in scoring.

# Consumable types
## **Scraps**
Used for new card enhancements to avoid conflict with tarot cards.

## Scraps
[] **Calcium**: Select 1 card to enchant with **Bone**
